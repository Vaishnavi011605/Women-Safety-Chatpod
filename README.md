# Women-Safety-Chatpod 🛡️

> A comprehensive chatbot application dedicated to women's safety, providing emergency assistance, self-defense tips, travel safety guidance, legal rights information, and mental health support resources.

## 📋 Overview

Women-Safety-Chatpod is an intelligent chatbot built to empower women with critical safety information and resources. The application was developed as a hackathon project with a mission to provide accessible support for women facing various safety concerns.

### Key Features

- 🚨 **Emergency Helplines** - Quick access to emergency contacts and hotlines
- 🥋 **Self-Defence Tips** - Practical self-defense techniques and tutorials
- ✈️ **Solo Travel Safety** - Comprehensive guidelines for safe solo travel
- ⚖️ **Legal Rights** - Information about women's rights and legal protections
- 💭 **Mental Health Support** - Resources for mental wellness and psychological support
- 💬 **Interactive Chat Interface** - User-friendly conversational experience

## 🛠️ Tech Stack

- **Backend**: Java
- **Frontend**: HTML5, CSS3, JavaScript
- **Architecture**: Client-Server Model

## 🚀 Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or higher
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Git

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Vaishnavi011605/Women-Safety-Chatpod.git
cd Women-Safety-Chatpod
```

2. Compile the Java files:
```bash
javac -d bin src/**/*.java
```

3. Run the application:
```bash
java -cp bin MainClass
```

4. Open your web browser and navigate to:
```
http://localhost:8080
```

## 💡 How to Use

1. **Start the Application** - Launch the chatbot
2. **Select a Category** - Choose from Emergency, Self-Defence, Travel Safety, Legal Rights, or Mental Health
3. **Chat with the Bot** - Ask questions or request information
4. **Get Assistance** - Receive tailored information and resources
